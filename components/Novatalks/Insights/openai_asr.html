### OpenAI [ASR] Novatalks Insights component for audio transcription via OpenAI Whisper API. Receives a dialog object (or array of dialogs), resolves audio file path(s) from configurable `Audio Path`, transcribes each file via Whisper, merges and sorts segments chronologically, and emits one output message per dialog. ## Inputs / Outputs - **Input** — Single dialog object or array of dialogs - **Output** — One message per transcribed dialog (passthrough fields + `transcription` object) - **debug** — Formatted debug/error messages ## Audio Path Resolution The `Audio Path` field is a dot-notation path resolved against the input data: - `processed.audio` → resolves `data.processed.audio` — expects array of file paths (APM output) - `someAudioPath` → resolves `data.someAudioPath` — expects a string file path - Any resolved string is automatically wrapped into a single-element array ## Participant Type Assignment Assigned by array index position of resolved audio files: | Files count | Index 0 | Index 1 | |---|---|---| | 1 file | Mono channel type | — | | 2 files | Left channel type | Right channel type | ## Output payload ```json { "documentID": "...", "transcription": { "full": "Hello I need help. Of course.", "segments": [ { "start": 0.0, "end": 3.2, "participant": "Customer", "transcribingTime": 520, "text": "Hello I need help." }, { "start": 4.1, "end": 7.5, "participant": "Agent", "transcribingTime": 480, "text": "Of course." } ] } } ``` Segments from all channels are merged and sorted by `start` time. ## Configuration - **API Key** — OpenAI API key (supports `{{ $FLOW_VARS.openai_api_key }}` flow variable) - **Model** — Whisper model to use - **Language** — Whisper language code - **Audio Path** — Dot-notation path to audio file(s) in input data - **Parallel Processes** — Max concurrent dialog transcription jobs (semaphore limit) ## Requirements - npm: `openai`, `async-sema` (auto-installed via `exports.npm`)
