# Save files Moves uploaded files from their temporary location to a permanent store path. Extends the native `Uploaded files` component with dynamic path templates, automatic date/time directory injection, and flexible output shaping. ## Inputs / Outputs - **Payload** — Incoming message containing a files array (from `Route [advanced]` or similar) - **Output** — Processed result (shape depends on Pass Request / Embed Store Path settings) - **error** — Fired on any OS-level move failure or on an Embedding Key Path collision: `{ "status": "500 Internal Server Error", "text": "..." }` - **debug** — Formatted debug/error messages when debug is enabled ## Main Settings ### Files Path Dot-notation path to the files array inside the incoming payload. Default: `files`. | Example payload key | Files Path value | |---|---| | `{ "files": [...] }` | `files` | | `{ "request": { "files": [...] } }` | `request.files` | ### Store Path Absolute destination path for each file. Supports template variables: | Expression | Resolves to | |---|---| | `{{ $data.files.filename }}` | Uploaded file name (e.g. `test.wav`) | | `{{ $data.files.extension }}` | File extension without dot (e.g. `wav`) | | `{{ $data.files.name }}` | Form field name (e.g. `RecordingFile`) | | `{{ $data.payload.DialogID }}` | Any other key from the input payload | | `{{ $FLOW_VARS.basePath }}` | TotalJS Flow global variable | Default: `/tmp/{{ $data.files.filename }}.{{ $data.files.extension }}` ### DateTime Embedding When **True** (default), injects `YYYY/MM/DD/HH` before the filename in Store Path: ``` /Recordings/test.wav → /Recordings/2026/05/01/14/test.wav /Recordings/audio/test.wav → /Recordings/audio/2026/05/01/14/test.wav ``` ### DateTime Path Source for the date/time used in embedding. Leave empty to use the current server time. - Static value: `1748000125` or `2026-04-30T14:34:13.000` - Template: `{{ $data.DialogTimeEnd }}` Accepted formats: Unix Epoch (10-digit seconds or 13-digit ms) and ISO 8601 strings. Invalid or missing values fall back silently to the current time. ## Advanced Settings ### Pass Request - **False** (default) — Output contains only the files array under its key, each file extended with `storedPath` - **True** — Output contains the entire input payload, with the files array extended in place ### Embed Store Path Requires **Pass Request = True**. When **True**, writes the stored path value directly into the key specified by **Embedding Key Path**. - Single file → the key receives a string: `"/path/to/file.wav"` - Multiple files → the key receives an array: `["/path/1.wav", "/path/2.wav"]` ### Embedding Key Path The exact output key to write the stored path value into. Default: `{{ $data.storedPath }}`. - Must point to a key that does **not yet exist** in the output — if the key already holds a value, the message is routed to the **error** output instead of overwriting it - Supports any depth: `{{ $data.request.payload.filePath }}` writes directly to `data.request.payload.filePath` ## Output shapes ### Pass Request = False ```json { "files": [ { "storedPath": "/Recordings/2026/05/01/14/test.wav", "filename": "test.wav", "removable": false, "index": 0, ... } ] } ``` ### Pass Request = True, Embed Store Path = False ```json { "headers": { ... }, "payload": { ... }, "files": [ { "storedPath": "/Recordings/2026/05/01/14/test.wav", "removable": false, ... } ] } ``` ### Pass Request = True, Embed Store Path = True, Embedding Key Path = `{{ $data.payload.filePath }}` ```json { "headers": { ... }, "payload": { "DialogID": "testID-17022", "filePath": "/Recordings/2026/05/01/14/test.wav" }, "files": [ ... ] } ``` ## Notes - Each moved file has `removable` set to `false`, gains a `storedPath` key, and loses the temporary `path` key - If any file fails to move, the message is immediately routed to the **error** output and processing stops - If **Embedding Key Path** points to a key that already exists, the message is routed to the **error** output — the existing value is never overwritten - Parent directories are created automatically if they do not exist
